# Farmer Crop Advisory Platform
AI-Based Smart Decision Support System for Farmers

A full-stack, enterprise-grade agricultural decision support platform powered by Machine Learning, Deep Neural Models, and multi-model LLMs (AgriLLM-Neural, Google Gemini, Groq Llama 3, OpenAI GPT-4o).

## Features
- **Crop Recommendation**: Multi-parameter NPK, pH, moisture, and rainfall optimization using Random Forest & XGBoost.
- **Precision Fertilizer Engine**: Split-dose schedules for Urea, DAP, MOP + bio-fertilizers.
- **Disease Diagnosis**: Computer vision CNN for plant pathology identification.
- **Yield Estimation**: Harvest output prediction per acre with financial ROI metrics.
- **AgriAI LLM Expert**: 24/7 conversational agricultural guidance in English, Telugu, and Hindi.
- **Weather Telemetry & Mandi Rates**: Live APMC market rates and 5-day agro-meteorological forecasts.
